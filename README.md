# spreadsheet_software_nsu

Табличный процессор для терминала, лабораторная работа №2 по основам ООП (вариант Г).

Программа состоит из ядра (`ss_core`: формулы, пересчёт, файлы), логики работы с программой (`ss_app`: курсор, режимы, клавиши, команды, фоновая загрузка) и интерфейса на FTXUI (`ss_tui`). Устройство программы описано в [DESIGN.md](DESIGN.md).

## Сборка и тесты

Нужны Linux, компилятор с C++20 (проверялось на GCC 15) и CMake 3.24+. FTXUI и GoogleTest скачиваются сами при первой сборке.

```sh
cmake --preset debug && cmake --build --preset debug && ctest --preset debug
```

Пресеты:

- `debug` — обычная отладочная сборка;
- `release` — с оптимизацией;
- `asan` — с AddressSanitizer и UndefinedBehaviorSanitizer, ловит утечки и обращения к освобождённой памяти.

Все свои цели собираются с `-Wall -Wextra -Wpedantic -Wshadow -Werror`.

## Запуск

```sh
build/debug/tui/spreadsheet             # пустая таблица
build/debug/tui/spreadsheet table.sst   # сразу открыть файл
```

Сверху строка формулы, снизу строка состояния: режим, имя файла (`*`, если есть несохранённые изменения) и сообщения. Программа рассчитана на окно от 80×24 и перерисовывается при изменении его размера. Управление только с клавиатуры. Ctrl+C программу не закрывает, чтобы не потерять несохранённую таблицу, выход это `ctrl+q` или `:q`.

## Формулы

Формула начинается с `=`: `=A1*2+SUM(B1:B3)`.

- Операции: `+ - * /`, унарный минус, скобки, сравнения `= <> < <= > >=` (дают 1 или 0).
- Ссылки `A1`, `$A$1`, диапазоны `A1:B3`. Столбцы от `A` до `ZZ`, строки от 1 до 65536.
- Функции: `SUM`, `MIN`, `MAX`, `AVERAGE`, `IF(условие, да, нет)`. Аргументы через запятую, имена без учёта регистра. В `IF` считается только выбранная ветка.
- Ошибки показываются в ячейке: `#DIV/0!`, `#REF!` (ссылка за пределы листа), `#NAME?` (нет такой функции), `#VALUE!` (например, число плюс текст), `#CYCLE!` (циклическая ссылка, и у всех, кто от неё зависит).

Что ещё можно ввести в ячейку:

- число (`12`, `-0.5`, `1e3`); пробелы по краям ввода отбрасываются;
- текст; если текст похож на число, а нужен именно текст, впереди ставится апостроф: `'123`;
- пустой ввод очищает ячейку.

При изменении ячейки пересчитываются только те, что от неё зависят, каждая ровно один раз.

## Клавиши

Режимы: обычный, правка ячейки, командная строка (после `:`) и справка.

| Клавиша | Что делает |
|---|---|
| стрелки, `h` `j` `k` `l` | перемещение |
| `pageup`, `pagedown` | на экран вверх или вниз |
| `home` | в столбец A |
| `ctrl+home` | в ячейку A1 |
| `enter`, `f2` | править ячейку, в строке её текущее содержимое |
| любой другой символ | начать правку с этого символа (старое содержимое заменится) |
| `delete` | очистить ячейку |
| `:` | командная строка |
| `?`, `f1` | справка |
| `ctrl+s` | сохранить |
| `ctrl+q` | выйти |

Из-за `hjkl` правка не начнётся с букв `h`, `j`, `k`, `l`: для них сначала нажмите `enter` или `f2`.

В правке: `enter` записывает и переходит вниз, `tab` записывает и переходит вправо, `esc` отменяет, работают `left`, `right`, `home`, `end`, `backspace`, `delete`. Если формула с ошибкой, правка не закрывается, а ошибка видна в строке состояния.

### Свои клавиши

Клавиши настраиваются в `~/.config/spreadsheet/keys.conf`. Пример со всеми значениями по умолчанию лежит в [config/keys.conf](config/keys.conf).

```
# клавиша = действие
ctrl+w = save
H = go-home
```

Можно назначить только часть клавиш, остальные останутся по умолчанию. Если строка с ошибкой (нет `=`, неизвестная клавиша или действие), она пропускается, а при запуске выводится предупреждение с номером строки. Если файла нет, берутся клавиши по умолчанию.

Имена клавиш: `up down left right enter esc backspace delete tab home end pageup pagedown f1`…`f12`, `ctrl+<клавиша>` и любой один символ (`h`, `?`, `ж`). У одиночных символов регистр важен, у остальных нет.

## Команды

Вводятся после `:`, например `:w table.sst`.

| Команда | Коротко | Что делает |
|---|---|---|
| `save [файл]` | `w` | сохранить; без имени в текущий файл |
| `open файл` | `e` | открыть `.sst` |
| `import-csv файл` | `import` | загрузить CSV |
| `quit` | `q` | выйти; не выходит, если есть несохранённые изменения |
| `force-quit` | `q!` | выйти без сохранения |
| `show-help` | `help` | справка |

Можно вызвать по имени и любое действие из таблицы клавиш: `move-up`, `move-down`, `move-left`, `move-right`, `page-up`, `page-down`, `go-home`, `go-top`, `start-edit`, `clear-cell`, `command-mode`. Путь к файлу пока не может содержать пробелов.

Файлы открываются в фоне, интерфейс в это время работает. Если файл битый, текущая таблица не меняется, а в строке состояния видно, что не так и в какой строке. Сохранение сначала пишет временный файл и потом переименовывает его, поэтому сбой посреди записи не портит старый файл.

## Формат `.sst`

Текстовый файл в UTF-8. Первая строка `SST 1` (подпись и версия), дальше по строке на непустую ячейку: адрес, таб и то, что ввёл пользователь.

```
SST 1
A1	42
B2	=A1*2
C3	text with \t tab and \\ backslash
```

В тексте ячейки `\` пишется как `\\`, таб как `\t`, перевод строки как `\n`. Пустые строки пропускаются, окончания строк `\r\n` тоже понимаются. Если подпись не та, адрес кривой, формула с ошибкой или встретилась неизвестная последовательность вроде `\x`, файл не открывается, а в ошибке указан номер строки.

## Импорт CSV

- Поля через запятую по RFC 4180. В кавычках могут быть запятые и переводы строк, кавычка внутри пишется как `""`.
- Первое поле первой строки попадает в A1. Строки могут быть разной длины, пустые поля пропускаются.
- Всё читается как число или текст. **Формулы из CSV не выполняются**: `=1+1` станет текстом `=1+1`. Это сделано специально, чтобы чужой файл не мог подсунуть формулу.
- UTF-8 с BOM (так сохраняет Excel) тоже читается.
- Незакрытая кавычка или текст сразу после закрывающей кавычки дают ошибку с номером строки.
- После импорта у таблицы нет файла, поэтому для сохранения нужно указать имя: `:w table.sst`. Сохранять в CSV на первом этапе нельзя.
